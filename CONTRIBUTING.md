# Contribuindo — navestory SaaS

Consulte o guia completo em [`docs/contributing.md`](docs/contributing.md).

## Resumo rápido

1. Branch: `feature/sua-feature` a partir de `master`
2. Spec aprovada em `specs/<domínio>/` antes de implementar
3. PR sem documentação atualizada é rejeitado
4. Commits no padrão Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`)
5. Rodar `pnpm lint` e testes antes do push

Dúvidas: abra uma Issue.
