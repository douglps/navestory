## Contexto

O PRD (RF-007) lista "export CSV" como entregável do Dashboard MVP. Hoje o Dashboard retorna estatísticas e despesas recentes via `GET /dashboard/stats`, mas não oferece nenhum mecanismo de exportação. Usuários (especialmente gestores de frota — P-002) precisam exportar dados para planilhas externas (Excel, Google Sheets) para controle financeiro e prestação de contas.

## Objetivo

Disponibilizar um endpoint `GET /dashboard/export` e um botão "Exportar CSV" no Dashboard que permita baixar as despesas do período selecionado em formato CSV compatível com Excel (UTF-8 BOM).

## Requisitos Funcionais

| ID | Requisito | Prioridade |
|----|-----------|------------|
| RF-01 | Endpoint `GET /dashboard/export` retorna arquivo CSV das despesas | Alta |
| RF-02 | Filtro obrigatório: `period` no formato `YYYY-MM` (mês/ano) | Alta |
| RF-03 | Filtro opcional: `vehicle_id` para exportar apenas um veículo | Média |
| RF-04 | Colunas do CSV: Data, Veículo (Placa), Veículo (Modelo), Categoria, Descrição, Valor (R$) | Alta |
| RF-05 | Arquivo com BOM UTF-8 para compatibilidade com Excel (evita problema de acentuação) | Alta |
| RF-06 | Nome do arquivo: `nave-despesas-{YYYY-MM}.csv` | Baixa |
| RF-07 | Botão "Exportar CSV" no Dashboard com seletor de mês/ano | Alta |
| RF-08 | Usuário só exporta dados próprios (isolamento por `user_id` do JWT) | Alta |
| RF-09 | Exportação de manutenções: fora de escopo nesta spec (Fase 2) | — |

## Requisitos Não-Funcionais

| ID | Requisito | Métrica de Aceite |
|----|-----------|------------------|
| RNF-01 | Performance | Resposta em < 500ms para até 1.000 registros |
| RNF-02 | Segurança | Requer `SupabaseAuthGuard` — sem acesso anônimo |
| RNF-03 | Tamanho máximo | Limite de 5.000 linhas por exportação (evitar timeout) |
| RNF-04 | Rate limiting | Throttle de 10 req/5min no endpoint de export |

## Critérios de Aceite

- [ ] CA-01: `GET /dashboard/export?period=2026-05` retorna CSV com `Content-Type: text/csv`
- [ ] CA-02: CSV contém colunas: Data, Placa, Modelo, Categoria, Descrição, Valor
- [ ] CA-03: Valores monetários no formato `150.00` (ponto como separador decimal no dado, formatação local fica no Excel)
- [ ] CA-04: Arquivo abre corretamente no Excel em português (acentos sem garbled text)
- [ ] CA-05: Sem access token válido → 401 Unauthorized
- [ ] CA-06: Filtro `vehicle_id` retorna apenas despesas do veículo informado
- [ ] CA-07: Período sem despesas retorna CSV apenas com cabeçalho (não erro 404)
- [ ] CA-08: Botão no Dashboard abre download diretamente (sem nova aba)

## Fora de Escopo

- Não inclui: Export de manutenções (Fase 2)
- Não inclui: Export em XLSX nativo (complexidade de dependência)
- Não inclui: Export de todos os períodos de uma vez (sem filtro de data)
- Não inclui: Email automático do CSV
- Não inclui: Agendamento de exports recorrentes

## Dependências

|------|-----------|-----------|

| Módulo | `dashboard` | Export será um novo endpoint no DashboardController |

## Notas Técnicas

**Endpoint:**
```
GET /dashboard/export?period=2026-05&vehicle_id={optional-uuid}
Authorization: Bearer {access_token}

Response:
  Content-Type: text/csv; charset=utf-8
  Content-Disposition: attachment; filename="nave-despesas-2026-05.csv"
  Body: BOM + CSV
```

**Geração do CSV no NestJS:**
```typescript
// DashboardController
@Get('export')
@UseGuards(SupabaseAuthGuard)
@Throttle({ default: { limit: 10, ttl: 300000 } }) // 10 req/5min
async exportCsv(
  @UserId() userId: string,
  @Query('period') period: string,
  @Query('vehicle_id') vehicleId: string | undefined,
  @Res() res: Response,
) {
  const csv = await this.dashboardService.exportExpensesCsv(userId, period, vehicleId);
  res.setHeader('Content-Type', 'text/csv; charset=utf-8');
  res.setHeader('Content-Disposition', `attachment; filename="nave-despesas-${period}.csv"`);
  res.send('﻿' + csv); // BOM prefix
}
```

**Query SQL (via Supabase):**
```typescript
const { data } = await this.supabase.client
  .from('expenses')
  .select('date, amount, category, description, vehicles(plate, model)')
  .eq('user_id', userId)
  .gte('date', `${period}-01`)
  .lte('date', lastDayOfMonth)
  .is('deleted_at', null)
  .order('date', { ascending: false });
```

**Geração manual do CSV:**
```typescript
const header = 'Data,Placa,Modelo,Categoria,Descricao,Valor\n';
const rows = data.map(e =>
  `${e.date},${e.vehicles.plate},${e.vehicles.model},${e.category},"${e.description ?? ''}",${e.amount}`
).join('\n');
return header + rows;
```

**Alternativa descartada — geração no frontend:** Transferir todos os dados ao cliente e gerar via Blob aumenta o tráfego e expõe todos os dados em memória. Server-side é mais seguro e performático para grandes volumes.

**Validação do `period`:** Regex `^\d{4}-(0[1-9]|1[0-2])$` — retornar 400 se inválido.
